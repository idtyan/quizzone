# QuizZone MVP

Это первая рабочая версия развлекательного сайта с тестами.

## Что уже есть
- Главная страница
- Категории
- Карточки тестов
- Страница теста
- Результат
- Кнопка «Поделиться»
- Адаптивная мобильная версия
- SEO title/description

## Как запустить
Можно просто открыть `index.html` в браузере.

Для публикации:
1. Создать репозиторий GitHub.
2. Загрузить эти файлы.
3. Подключить репозиторий к Vercel или другому хостингу.
4. Подключить собственный домен.
